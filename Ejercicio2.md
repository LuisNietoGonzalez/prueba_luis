# Ejercicio 2: Sintaxis de Markdown

## Repaso de los elementos básicos

Markdown es un lenguaje de marcado ligero que permite dar formato al texto de forma sencilla. Con él podemos escribir palabras en **negrita**, otras en *cursiva* y también fragmentos de `código` dentro de una frase, como por ejemplo `git status`.

```python
def saludar(nombre):
    print(f"Hola, {nombre}")

saludar("mundo")
```

1. Crear el fichero Markdown.
2. Añadir los elementos de sintaxis.
3. Revisar el resultado.

* Títulos
* Listas
* Enlaces
* Imágenes
